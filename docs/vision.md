# Видение портфолио

## Назначение

Создать профессиональное портфолио системного аналитика, которое демонстрирует практические навыки через связанные между собой проекты, аналитические артефакты и техническую документацию.

Портфолио должно позволять работодателю быстро понять уровень подготовки кандидата и увидеть примеры реальной работы с требованиями, процессами, данными, API и архитектурой.

---

## Целевая аудитория

Портфолио ориентировано на:

- HR-специалистов;
- IT-рекрутеров;
- руководителей команд;
- системных аналитиков;
- технических интервьюеров;
- Product Managers;
- Project Managers.

---

## Ценность портфолио

Портфолио должно помогать работодателю быстро определить:

- какие задачи системного анализа я умею решать;
- какие аналитические артефакты я умею создавать;
- как я работаю с требованиями;
- как моделирую бизнес- и системные процессы;
- как проектирую модели данных;
- как описываю REST API;
- как связываю требования, данные, API и архитектуру;
- насколько структурированно оформляю проектную документацию.

---

## Основной принцип

Портфолио строится не как набор отдельных учебных файлов, а как связанная проектная документация.

Каждый основной артефакт должен быть связан с другими частями проекта:

`Requirements → BPMN → ERD → SQL → API → UML → Architecture`

---

## Основной проект

Основным проектом портфолио является **Smart Home Management Platform** — система управления умным домом.

На его примере демонстрируется полный цикл системного анализа:

- постановка задачи;
- определение требований;
- моделирование процессов;
- проектирование модели данных;
- разработка SQL-схемы;
- описание REST API;
- моделирование взаимодействия компонентов;
- описание архитектуры системы.

---

## Критерий готовности

Портфолио считается готовым к использованию при поиске работы, если:

- основные разделы проекта оформлены;
- документы связаны между собой;
- ссылки внутри GitHub работают;
- диаграммы читаются без дополнительных программ;
- нет временных или служебных файлов;
- основной README позволяет быстро перейти к ключевым артефактам.
