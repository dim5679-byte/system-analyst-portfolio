# BPMN

## Назначение раздела

В разделе представлены BPMN-диаграммы основных бизнес-процессов Smart Home Management Platform.

Диаграммы используются для детализации пользовательских сценариев, согласования логики работы системы и передачи требований разработчикам.

## Возможное развитие

В дальнейшем могут быть дополнительно смоделированы процессы:

- авторизация пользователя;
- создание дома;
- создание комнаты;
- удаление устройства.

Эти процессы не входят в обязательный набор артефактов первой версии портфолио.
