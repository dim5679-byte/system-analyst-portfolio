# SQL

## Назначение раздела

В разделе представлены SQL-скрипты для модели данных Smart Home Management Platform.

Структура базы данных основана на ERD проекта и реализована для PostgreSQL.

---

## Используемая СУБД

PostgreSQL

---

## Основные таблицы

- `users`
- `homes`
- `home_members`
- `rooms`
- `device_types`
- `devices`
- `device_states`
- `commands`

---

## Особенности схемы

В схеме используются:

- UUID в качестве первичных ключей;
- внешние ключи для обеспечения связности данных;
- индексы для основных полей поиска и связей;
- JSONB для хранения состояния устройств;
- уникальность Email без учета регистра;
- триггеры для автоматического обновления `updated_at`.

## Примеры запросов

В `02-sample-queries.sql` представлены запросы для:

- получения домов пользователя;
- просмотра комнат и устройств;
- получения текущего состояния устройства;
- просмотра участников дома;
- получения истории команд;
- определения последней команды устройства;
- подсчета команд по статусам.

Именованные параметры вида `:user_id`, `:home_id` и `:device_id` используются как placeholders и предполагают подстановку значений приложением.
