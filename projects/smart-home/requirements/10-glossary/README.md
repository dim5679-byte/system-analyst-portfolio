# Glossary

## Назначение

Глоссарий содержит основные термины, используемые в проекте Smart Home Management Platform.

---

## Термины

| Термин | Определение |
|---|---|
| Пользователь | Зарегистрированный пользователь системы Smart Home Management Platform. |
| Дом | Логическая сущность, объединяющая помещения, устройства и пользователей в рамках одного объекта. |
| Комната | Помещение внутри дома, к которому могут быть привязаны устройства. |
| Устройство | Физическое IoT-устройство, подключенное к системе умного дома. |
| Тип устройства | Категория устройства, например лампа, розетка, датчик или термостат. |
| Состояние устройства | Текущее состояние устройства, например включено/выключено, температура или другие параметры. |
| Команда | Запрос пользователя на изменение состояния устройства. |
| Владелец дома | Пользователь, создавший дом и обладающий полными правами управления. |
| Участник дома | Пользователь, которому владелец предоставил доступ к дому. |
| JWT | Токен, используемый для аутентификации пользователя при обращении к API. |
| REST API | Интерфейс взаимодействия клиентского приложения с backend-сервисом по HTTP. |
| IoT Gateway | Компонент, обеспечивающий взаимодействие backend-системы с физическими IoT-устройствами. |
